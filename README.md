## 📱 客户端配置方法

### 🍎 iOS / iPadOS / Apple TV (APTV)
1. 打开 **APTV**；
2. 点击右上角 **“+”** -> 选择 **“添加配置”**；
3. 选择 **“网络链接”**；
4. 粘贴上方任一订阅链接即可，APTV 将每日在后台自动静默更新。

### 🤖 Android 手机 / Android TV
1. 在 App 设置中选择 **【自定义 M3U 订阅】**；
2. 填入上方订阅链接即可一键刷新！
